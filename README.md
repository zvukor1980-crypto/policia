# Полиция: Ночной патруль (версия 2.0)

Детективная игра: ходите по ночному городу, ищите улики, допрашивайте свидетелей,
собирайте доску дела и отправляйте виновных в тюрьму.

Управление: нажмите или проведите пальцем (на компьютере — мышкой) туда, куда
должна идти героиня. Нажмите на блестящую точку или на человека, чтобы подойти
и осмотреть / поговорить. Машин в этой версии нет.

Веб (айфон и компьютер): https://zvukor1980-crypto.github.io/policia/
На iPhone в Safari: «Поделиться» → «На экран Домой».

Windows: Policia.exe в папке на рабочем столе «Полиция Ночной патруль».
